# 🏥 MediCitas - Sistema de Gestión Médica

Sistema web desarrollado en **ASP.NET Core MVC (v9)** para la administración integral de clínicas médicas, control de pacientes, doctores, agenda diaria de citas y expedientes de historiales clínicos, conectado a una base de datos **MariaDB** mediante `MySqlConnector`.

---

## 🚀 Características Principales

* **Gestión de Pacientes y Doctores:** Registro y control completo de información personal y profesional.
* **Módulo de Citas:** Creación, visualización de citas agendadas, canceladas y cambio de estados.
* **Agenda Diaria:** Filtrado de citas por fecha y selección específica de médicos.
* **Historial Clínico y Consultas:** Registro de diagnósticos, recetas y observaciones por paciente.
* **Especialidades Médicas:** Resumen agrupado por especialidad con listado de doctores disponibles.
* **Diseño UI Moderno:** Interfaz responsiva basada en Bootstrap con temática *"Emerald Green"*.

---

## 🛠️ Tecnologías Utilizadas

* **Backend:** C#, ASP.NET Core MVC (.NET 9)
* **Base de Datos:** MariaDB (`citas_medicas_db`)
* **Conector:** `MySqlConnector`
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
* **Entorno de Desarrollo:** Visual Studio Code / Docker
